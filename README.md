# Pork & Garlic Ice Cream — Year 2 Decision Lab

An original static decision-support website based on the supplied Year 1 workbook.

## What it does
- Displays verified Year 1 baseline results.
- Lets the user edit two different Year 2 Winter scenarios.
- Recalculates revenue, production limits, spoilage, profit and closing cash.
- Checks market investment, sales increments, trainer allocation, machine capacity, milk capacity, debt cap, loan term and cash risk.
- Provides a Year 1 validation cross-check, side-by-side comparison and a student recommendation area.

## Deploy on Vercel
This is a zero-build static project. Import the GitHub repository into Vercel and deploy with default settings.

## Important modelling assumptions
- Year 2 opens with the Year 1 closing cash balance of Sh -144,853.
- Existing Year 2 capacity is 192,000 units from machines 1 and 2.
- Existing machine maintenance is Sh 4,700 per season.
- Existing depreciation is Sh 16,250 per season.
- Sale price is Sh 2 per allocated unit.
- Salary bonus is 5% of positive gross profit, matching the supplied Year 1 workbook.
- The Sh 167,978 Year 1 tax-loss pool offsets positive Year 2 Winter profit before game tax is applied.
- New loans use 10% seasonal interest and equal principal repayment in this simplified one-season decision model.
- Trainer sales allocation remains an external estimate, not guaranteed sales.

Update these assumptions when official Year 2 rules are released.
